# Rotina Acadêmica

Aplicativo móvel em React Native, Expo SDK 57, Expo Router e TypeScript.

## Executar

Requer Node 24.21.0 e npm (`package-lock.json`).

```bash
nvm use
npm ci
npx expo start
```

Abra o projeto no Expo Go ou em um emulador Android. O código das telas fica em `src/app/`; componentes reutilizáveis ficam em `src/components/`.
